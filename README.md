# سبورة الرياضيات

سبورة رياضيات تفاعلية للمدرسين: أسئلة المنهج العراقي والوزاريات، من الأول متوسط إلى السادس الإعدادي (العلمي والأدبي).
تشتغل **كموقع** و**كتطبيق ينصب**، و**بدون إنترنت** بعد أول فتح.

## محتويات المجلد

| الملف | شنو يسوي |
|---|---|
| `index.html` | السبورة نفسها |
| `sw.js` | عامل الخدمة: يحفظ السبورة بالجهاز حتى تشتغل بدون نت |
| `manifest.webmanifest` | يخلي المتصفح يعرف إنها تطبيق (الاسم، الأيقونة، الألوان) |
| `icons/` | أيقونات التطبيق |
| `.nojekyll` | ضروري لـ GitHub Pages، لا تمسحه |

## الرفع على GitHub Pages (أول مرة)

1. سجّل دخول على github.com واضغط **New repository**.
2. سمّه مثلاً `sabora` واختار **Public** ثم **Create repository**.
3. اضغط **uploading an existing file**، واسحب **كل محتويات المجلد** (مو المجلد نفسه) وبيها مجلد `icons`، ثم **Commit changes**.
4. روح لـ **Settings ← Pages**، وبـ **Branch** اختار `main` و `/(root)` ثم **Save**.
5. بعد دقيقة أو دقيقتين يصير الرابط: `https://اسم-حسابك.github.io/sabora/`

## الاشتراكات

- الفصل الأول من كل صف **مجاني** للتجربة، وباقي الفصول تنفتح بكود اشتراك.
- الباقات: `mid` الدراسة المتوسطة، `sci` الفرع العلمي، `lit` الفرع الأدبي، `all` الكل.
- الأكواد تندار من Google Sheet خاص (مو بهذا المستودع). محتوى الفصول المقفلة **مشفّر** بالملف، فما ينفتح بدون كود حتى لو أحد نزّل الموقع.
- بعد التفعيل تشتغل بدون نت ٣٠ يوم، وكل ما يتصل بالنت تتجدد المدة تلقائياً.

## التثبيت كتطبيق

- **أندرويد (Chrome):** افتح الرابط ← يطلع زر «تثبيت» أسفل الشاشة، أو من القائمة ⋮ ← «تثبيت التطبيق».
- **آيفون/آيباد (Safari):** زر المشاركة ← «إضافة إلى الشاشة الرئيسية».
- **حاسبة (Chrome/Edge):** أيقونة التثبيت بشريط العنوان، أو زر «تثبيت» أسفل الصفحة.

بعد أول فتح وهو متصل بالنت، السبورة تشتغل بدون نت.

## نشر تحديث

1. ارفع `index.html` الجديد بدل القديم.
2. افتح `sw.js` وغيّر رقم النسخة بالسطر: `const VERSION = 'v1.0.0';` (مثلاً إلى `v1.0.1`).
3. **Commit changes**.

كل واحد عنده السبورة، أول ما يتصل بالنت يطلعله «وصل تحديث جديد للسبورة ← تحديث الآن».
> إذا ما غيّرت رقم النسخة، الأجهزة تبقى على النسخة القديمة.
